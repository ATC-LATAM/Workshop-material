# Flujos de trabajo con agentes de IA

**Laboratorio Abre Tu Ciencia - ATC 2026**

Sesión sobre el uso de agentes de inteligencia artificial para mejorar flujos de trabajo en ciencia de datos e investigación abierta.

## 📋 Objetivos de la sesión

Al finalizar esta sesión, los participantes serán capaces de:

1. **Conocer herramientas de IA para ciencia de datos**
   - Utilizar Positron Assistant para análisis de datos
   - Aprovechar el contexto ampliado (datos, plots, consola) en workflows de data science

2. **Dominar la ingeniería de prompts**
   - Identificar características de buenos y malos prompts
   - Escribir prompts efectivos para análisis estadísticos y programación
   - Aplicar mejores prácticas en la comunicación con asistentes de IA

3. **Evaluar herramientas de IA para ciencia abierta**
   - Comparar ventajas y desventajas de Cursor y LM Studio
   - Seleccionar la herramienta apropiada según necesidades de privacidad, costo y funcionalidad
   - Entender implicaciones éticas y de reproducibilidad

4. **Aplicar mejores prácticas**
   - Documentar el uso de IA en investigación
   - Mantener transparencia y reproducibilidad
   - Considerar aspectos de privacidad y compliance

## 🎯 Temas cubiertos

1. **Asistente de IA en Positron**
   - Chat pane e inline chat
   - Code completions
   - Contexto de data science

2. **Ingeniería de prompts**
   - Ejemplos de buenos y malos prompts
   - Caso práctico: modelo estadístico de calor y parto pretérmino

3. **Cursor**
   - Características principales (Composer, Chat contextual, Codebase indexing)
   - Ventajas y desventajas para ciencia abierta

4. **LM Studio**
   - Ejecución local de modelos LLM
   - Ventajas y desventajas para ciencia abierta
   - Consideraciones de privacidad y compliance

5. **Comparación y selección de herramientas**
   - Criterios para elegir entre diferentes opciones
   - Casos de uso específicos

6. **Mejores prácticas con IA**
   - Transparencia y documentación
   - Reproducibilidad
   - Consideraciones éticas
